Terminal, VS Code, JetBrains

The same review in every editor you use.

One backend, identical decisions across the CLI, VS Code, and JetBrains. Start reviewing in the terminal, finish in your editor — nothing to reconcile. A navigation bar rides along as you work — step through pending edits from the status bar, the editor tab, or a bubble over the change. And an Action Timeline surfaces every tool call Claude made, not just the edits — flagging the risky commands it ran and mapping where a session reached off-machine — at zero extra tokens.

No repo required

Standalone. Git-free. Shareable.

A content-addressed snapshot store records every edit itself — no repo, no commits, zero extra Claude tokens. Then hand the session to a teammate.

— or let Claude do it —

Paste this into a Claude Code session — it installs everything for you.

Install Claude Observatory for me — run its bootstrap installer, then `claude-observatory doctor`. The capture hooks only take effect on a fresh session, so afterward have me quit, run `claude-observatory init` in a plain terminal, and relaunch.

Already installed? Stay up to date by re-running the one-liner above, or run claude-observatory update — add --check to just see what's new.
