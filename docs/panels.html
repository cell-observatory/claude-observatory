Panels

Interface reference

Every window, tab, and toolbar button in the observatory, named and annotated — so documentation, issues, and support can refer to each control precisely. Screens are from VS Code; JetBrains mirrors them.

01

The workspace

Every region and toolbar, called out on one screen: the Claude Edits sidebar and the editor on top, the Claude Observatory bottom panel below, and the status bar along the bottom.

02

The panel views in detail

The observatory’s own views, with every part named: the Observations · Overview · Stats panes of the “Claude Observatory” bottom panel, plus Actions, which lives in the Claude Edits sidebar.

03

Status bar — navigation bar

The compact review toolbar beside the 🔬 microscope, shown whenever edits await review. The status bar is the only surface that shows live counters, and its clear button is the session-wide Clear resolved. The Overview panel’s title bar carries the same combined review nav bar (Search first on every surface, then File ◄► / Diff ◄► step-through, Keep · Undo · Accept/Reject File · the file-scoped Clear File · Spotlight) alongside its session selector and bulk actions.
